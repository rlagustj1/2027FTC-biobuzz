## ✅ 해결됨: -176 heading 정체 문제 (근본원인 = 회전 부호 반전)

**2026-07-08~09 세션에서 원인 규명·수정·실기 검증 완료.**

### 근본 원인
`TurnTest`·`DashboardDriveOpMode`가 `SIGN=+1`로 heading 제어를 했는데, **하드웨어상 `+w`가
물리적으로 CW(오른쪽)를 만들어** 부호가 반대였다. 그 결과 heading 피드백이 음(-)이 아니라
양(+)의 피드백으로 작동 → 목표에서 멀어지는 방향으로 발산. TurnTest에선 한 바퀴 돌다 래치로
얻어걸렸고(가짜 도달), DashboardDriveOpMode에선 -176도로 발산했다.
→ 사실 `GoToPointTest`가 이미 `w = -KP*eHeading`로 발견했던 것을 두 파일이 안 따랐던 것.

### 수정 (커밋 c6accc0)
- **`SIGN = -1.0`** 로 확정 — `TurnTest`·`DashboardDriveOpMode` 둘 다. `GoToPointTest`(-KP)와 통일.
- **실기 검증됨**: TurnTest 90도 목표가 **한 바퀴 안 돌고 짧게 90도만 돌아 수렴**(부호 정답 확인).
- dirLock "도달 즉시 해제" 누락 버그도 함께 수정(오버슈트 방지), 라이브 디버깅 텔레메트리 보강.

### 아직 안 끝난 것 (다음 세션, 로봇 필요)
1. **손밀기 Y축 오도 진단** (모터 OFF, 폭주 0): Dashboard Drive START → goto 안 보내고 → 로봇
   손으로 앞/뒤/좌/우 밀며 DS 텔레메트리 X·Y 확인. heading 0 맞추고: 앞으로 밀 때 X증가/Y불변,
   왼쪽 밀 때 Y증가/X불변이면 정상. (오늘 로봇 전원문제로 못 함) — 대시보드 위치+회전 통합의
   Y축 거동이 이상하다는 사용자 관찰이 있어서 이걸로 오도 vs 제어 문제를 가려야 함.
2. Y 원인 잡으면 → Dashboard Drive로 최종 재검증(위치+회전 통합).

### ⚠️ USB 자주 끊김 / 무선 배포
- USB가 계속 끊긴다(케이블 헐거움). 끊기면 `adb reconnect` + `adb forward tcp:9999 tcp:9999` 재설정 필요.

## 배포 방법 (USB, 매번 이렇게 함)

```powershell
# 1. adb 경로 (PATH에 없으면)
$ADB = "C:\Users\hyeon\AppData\Local\Android\Sdk\platform-tools\adb.exe"

# 2. 기기 확인
& $ADB devices

# 3. 빌드+설치 (JAVA_HOME 필요, Android Studio 번들 JDK 사용)
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
cd C:\Users\hyeon\AndroidStudioProjects\2027FTCbiobuzzseason
.\gradlew.bat :TeamCode:installDebug

# 4. RC 앱 실행 (재설치 후 자동 실행 안 될 때가 많음)
& $ADB shell am start -n com.qualcomm.ftcrobotcontroller/org.firstinspires.ftc.robotcontroller.internal.FtcRobotControllerActivity

# 5. 필요시 시계 설정 (재부팅 후 1970년이면)
& $ADB shell "date MMDDhhmmYYYY.ss"   # 예: date 070720002026.00 = 7/7 20:00 2026

# 6. 대시보드용 포트포워딩 (USB로 대시보드 테스트할 때)
& $ADB forward tcp:9999 tcp:9999
```

**중요**: USB 케이블이 자주 끊긴다 (adb reconnect 필요). 매번 `& $ADB devices`로 확인 후 진행.
재설치(uninstall 후 install) 시 **권한(위치/카메라/저장소)이 리셋**되므로 다시 grant 필요할 수 있음:
```powershell
& $ADB shell pm grant com.qualcomm.ftcrobotcontroller android.permission.ACCESS_FINE_LOCATION
# (CAMERA, READ_EXTERNAL_STORAGE, READ_PHONE_STATE, WRITE_EXTERNAL_STORAGE 등도 동일)
```
