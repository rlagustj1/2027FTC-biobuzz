# 대시보드 실행법 (원격 좌표 클릭 주행)

외부 PC 대시보드에서 필드를 클릭하면 로봇이 그 좌표로 이동한다.
`RobotCommServer`(로봇) ↔ `dashboard.py`(PC) 가 TCP로 통신.

## 공통: 로봇 쪽
1. DS 앱에서 **`Dashboard Drive`** OpMode → INIT → START
   - 통신서버(:9999) + 오도 + 경로추종이 함께 돎
2. ⚠️ 넓은 공간, STOP 손 근처 (대시보드로 먼 좌표 보내면 그만큼 이동)

---

## 방법 A: USB (개발/디버깅용, 인터넷 유지됨)

노트북이 일반 인터넷에 붙은 채로 USB로 로봇과 통신. adb 포트포워딩 사용.

```bash
# 1. 노트북 ↔ Control Hub USB 연결
# 2. 포트포워딩
adb forward tcp:9999 tcp:9999
# 3. 대시보드 실행 (로컬 주소)
cd pc
python dashboard.py --robot-host 127.0.0.1 --robot-port 9999
# 4. 브라우저: http://localhost:8000
```
adb 경로가 안 잡히면:
`C:\Users\hyeon\AppData\Local\Android\Sdk\platform-tools\adb.exe`

---

## 방법 B: WiFi (원격 데모용, 노트북 인터넷 끊김)

노트북을 로봇 WiFi에 붙여서 무선으로. **인터넷이 끊기므로 Claude와 대화 불가** —
완성품을 혼자 데모/테스트할 때 사용.

```bash
# 1. 노트북 WiFi를 FTC-be8o 로 변경 (비번: password)
# 2. 대시보드 실행 (로봇 IP 직접)
cd pc
python dashboard.py --robot-host 192.168.43.1 --robot-port 9999
# 3. 브라우저: http://localhost:8000
```

### WiFi 안 될 때 체크
- 노트북이 **정말 FTC-be8o에 붙었는지** 확인 (`raon_h_202` 등 딴 데 붙어있으면 안 됨)
- Control Hub Wi-Fi Band가 **2.4GHz**인지 (REV Hardware Client → Program and Manage)
- `ping 192.168.43.1` 되는지

## 대시보드 사용법
- 초록 점 = 로봇, 화살표 = heading, 파란 궤적 = 이동 경로
- **필드 클릭** → 그 좌표로 goto 명령 전송 → 로봇 이동
- 우측 입력칸으로 x, y, heading 직접 입력 후 "goto 전송"
- "ping" 버튼 → 왕복지연(RTT) 측정

## 현재 네트워크 정보 (재설치 시 바뀔 수 있음)
- SSID: `FTC-be8o` / 비번: `password` / 로봇 IP: `192.168.43.1` / 포트: `9999`
